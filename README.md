# 🏗️ Trockenbau-Assistent

Interaktive Schritt-für-Schritt Bauanleitung für drei Trockenbau-Metallständerwände.

## Wände
- 🅰️ **Wand 1 — Büro** · 4,25×3,00 m · Standard-Tür 875×2110 mm
- 🅱️ **Wand 2** · 1,98×3,00 m · Ohne Tür
- 🅲 **Wand 3** · 2,18×3,00 m · Rollstuhlgerechte Tür DIN 18040 ♿

## Features
- 8 Schritt-Typen pro Wand (Planung → Finish)
- Dynamische SVG-Grafiken pro Schritt
- CW-Raster 62,5 cm · Tür-Rohbaumaße automatisch berechnet
- Progress-Tracking

## Nutzung
`index.html` im Browser öffnen — läuft ohne Server.
